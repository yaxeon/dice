# Roll the dice

Приложение на обычных HTML, CSS и JavaScript. Чёрный экран, белые кубики с острыми краями, настройки в один ряд без текстовых подписей. d6 показывает точки; d4/d8/d10 — цифры на той же форме кубика.

Один кубик — по центру, два — вертикально, три — один сверху и два ниже.

## Запуск

Нужен Python 3; для тестов — Node.js 22 или новее. Устанавливать npm-пакеты не требуется.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть [приложение](http://127.0.0.1:4173/) или [статичный макет](http://127.0.0.1:4173/mockup.html). Если сервер уже запущен, повторно запускать его не нужно. Можно также использовать `npm start`.

Открытие `index.html` через `file://` не подходит для JS-модулей и service worker: запускайте через HTTP-сервер.

## Управление

- Тапнуть и отпустить: вращение в случайную сторону.
- Потянуть пальцем или мышью: кубики вращаются сразу по направлению движения. После отпускания они продолжают вращаться и плавно останавливаются.
- Нижние настройки: `1 / 2 / 3` кубика и `4 / 6 / 8 / 10` граней для всех кубиков.
- До первого броска и после смены настроек кубики показывают случайные начальные значения. Знака «—» нет.
- После броска кубики останавливаются основной гранью прямо к пользователю, без наклона.
- Звук перекатывания начинается вместе с анимацией броска после отпускания пальца или мыши. Пока кубики следуют за перетаскиванием, звука нет; к концу броска щелчки замедляются и затихают. Уход со страницы останавливает звук.
- Смена настройки сбрасывает результат; настройки сохраняются на устройстве.
- С клавиатуры: Tab до области броска, Enter или пробел. Настройки доступны кнопками через Tab.
- Системный режим уменьшенной анимации заменяет вращение коротким изменением прозрачности.

Результат каждого кубика выбирается через Web Crypto с отбрасыванием лишнего диапазона. Направление и скорость жеста управляют анимацией, не вероятностями. Повторы допустимы. [Web Crypto](https://developer.mozilla.org/en-US/docs/Web/API/Crypto/getRandomValues).

Звук синтезируется локально через Web Audio после действия пользователя, без загрузки аудиофайлов. Если браузер блокирует звук, броски продолжают работать. Громкость регулируется на устройстве. [Запуск AudioContext](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/resume).

## Хостинг через Docker и Traefik

`Dockerfile` использует [официальный Node.js Alpine](https://hub.docker.com/_/node) и [http-server](https://github.com/http-party/http-server) версии **14.1.1**, обслуживает приложение на порту **80** и проверяет его доступность через healthcheck. Сборка приложения не нужна. `http-server` устанавливается только в образ при сборке; локально npm-пакеты не требуются. В образ копируются только файлы приложения; `.dockerignore` исключает остальные файлы из контекста сборки.

Созданный вами `docker-compose.yml` уже совместим: Traefik направляет запросы для `dice.yaxeon.ru` в контейнер. HTTPS и сертификат обеспечивает Traefik. На сервере должны быть запущены Traefik с точкой входа `websecure` и resolver `myresolver`, а внешняя Docker-сеть `traefik` должна существовать. DNS домена должен указывать на сервер.

Загрузите проект на сервер и выполните из его папки:

```sh
docker compose up -d --build
```

Откройте [https://dice.yaxeon.ru/](https://dice.yaxeon.ru/). Этой же командой пересобирайте приложение после загрузки обновлённых файлов.

Локальная проверка контейнера без Traefik:

```sh
docker build -t rolldice:local .
docker run --rm -p 127.0.0.1:4174:80 rolldice:local
```

Адрес проверки — [http://127.0.0.1:4174/](http://127.0.0.1:4174/). Сервер запускается командой `http-server /app -a 0.0.0.0 -p 80 -c-1 -d false`: `-c-1` запрещает HTTP-кеширование всех файлов, включая `sw.js`, а `-d false` отключает листинг каталогов. MIME-типы определяются по расширениям файлов. Офлайн-кеш service worker сохраняется; локальный `npm start` по-прежнему запускает Python-сервер.

## Установка на телефон

Для установки с телефона опубликуйте приложение по **HTTPS**, например через Docker и Traefik, как описано выше. Адрес `127.0.0.1` доступен только на компьютере, где запущен сервер.

Публикуемые файлы: `index.html`, `styles.css`, все JS-файлы в корне, `manifest.webmanifest`, `sw.js` и папка `icons/`. Файлы `PLAN.md`, `mockup.html`, `tests/` и `scripts/` приложению не нужны. Все пути относительные: приложение можно разместить и в подпапке.

1. Откройте опубликованный HTTPS-адрес на телефоне с доступом в интернет.
2. На iPhone в Safari: «Поделиться» → «На экран Домой» → «Добавить».
3. На Android в поддерживаемом браузере: меню → «Установить приложение» или «Добавить на главный экран». Название пункта зависит от браузера.
4. Запускайте приложение из иконки. Оно открывается в режиме `standalone`.

После первой загрузки и завершения установки service worker файлы кешируются. Повторное открытие и броски доступны без сети. Установка на домашний экран сама по себе не заменяет первое успешное кеширование. [Установка PWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable).

## Проверки

```sh
npm test
```

Тесты проверяют диапазоны, отбрасывание смещённого хвоста, допустимость повторов, порог жеста, смену направления, второй указатель, паузу перед отпусканием, направление остановки, работу при недоступном хранилище и остановку звука при завершении или отмене.

Проверка без сети на компьютере: открыть приложение, дождаться установки service worker, остановить локальный сервер, перезагрузить вкладку и бросить кубики. Затем снова запустить сервер.

Для окончательной проверки установки нужны реальные iPhone/Safari и Android/Chrome: добавить на домашний экран, запустить из иконки, включить авиарежим и повторить бросок. Эмуляция размера экрана не проверяет установку на устройстве.

Локально проверено: все 12 сочетаний настроек; размеры 320×568, 390×844 и 844×390; восстановление настроек; перетаскивание и клавиатура; отпускание за пределами области броска; защита от повторных тапов. Приложение успешно перезагрузилось и бросило кубики при остановленном локальном сервере.

## Изменения и обновления

После изменения состава кеша или публикации новой версии увеличьте версию `CACHE_NAME` в `sw.js`. При успешной установке новой версии удаляются только старые кеши этого приложения. Сетевые запросы сначала получают актуальные файлы с сервера; при недоступной сети используются сохранённые файлы.

Иконки находятся локально. Их можно воспроизвести без дополнительных библиотек:

```sh
python3 scripts/generate-icons.py
```
